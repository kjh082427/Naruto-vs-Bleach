# 새 캐릭터 만들 때 준비할 파일

쥬라큘 미호크를 만들면서 실제로 필요했던 것과 도움이 된 자료를 정리했습니다. 새 캐릭터를 요청할 때 아래 파일을 `<캐릭터 영문 이름>/` 폴더 하나에 모아 주세요 (예: `Dracule Mihawk/`).

## 1. 꼭 필요한 것

| 파일 | 내용 | 어디에 쓰이나 |
|---|---|---|
| `description.txt` | 이름(한글/원어), 작품(블리치/나루토/원피스 진영), 외형 특징(머리색·모자·의상 색·무기 모양), 성격, 짧은 대사 3~4개 | 리스킨 기준, 등록부 이름·대사 |
| `일러스트.png` (1~2장) | 얼굴이 크게 나온 그림 1장 + 상반신/전신 그림 1장. 글자·워터마크 없는 것, 배경이 단순할수록 좋음 | 선택창 아이콘·초상, 대전 로딩 배너, 필살기 컷인 |
| `모델링.jpg` (1~2장) | 정면에 가까운 전신(또는 상반신) — 의상 색, 무기 형태, 모자 등 소품이 잘 보이는 것 | 게임 안 도트(스프라이트) 리스킨 기준 |
| 스킬 명세 (텍스트) | 키별 동작: J(일반 공격, 연타 단계 수), W+J, S+J, U, W+U, S+U, 공중 J/U, I, W+I, S+I, O(보조) — 무엇을 하는지, 이펙트 색, 띄우기/돌진/원거리 여부 | 기술 재조립, 공격력 테이블 |

## 2. 있으면 결과가 크게 좋아지는 것

| 파일 | 설명 |
|---|---|
| 스킬 참고 영상 (키별로 파일 분리) | 파일 이름에 키를 적어 주세요: `j.mp4`, `j+u.mp4`, `s+i.mp4` … 한 파일에 한 기술, 3~10초. 미호크 때는 3D 모바일 게임 녹화본이라 **동작 설계 참고용**으로만 썼습니다 |
| **2D 도트 게임 스프라이트** | 같은 캐릭터의 2D 격투게임 도트(스프라이트 시트, GIF, 게임 녹화)가 있으면 리스킨 대신 실제 그 캐릭터 그림을 쓸 수 있어 훨씬 원작에 가깝습니다 |
| 베이스 캐릭터 희망 | 무기·체형이 비슷한 기존 캐릭터 (예: 대검 검사 → 이치고 만해/켄파치, 맨손 → 루피/나루토). 없으면 제가 후보를 골라 여쭙니다 |
| 목소리 파일 | 기합·기술명 음성 (mp3/wav, 짧게 잘린 것). 없으면 베이스 캐릭터 목소리를 무음 처리합니다 |
| 전용 BGM | mp3 1곡 (없으면 진영 음악 사용) |

## 3. 정하면 좋은 것 (안 정하면 제가 기본값으로)

- 진영: 블리치 / 나루토 / 원피스 — 선택창 블록 위치와 스토리 모드 상대가 정해짐
- 스토리 모드 라이벌 2명 (`vs`)
- CPU가 쓸 보조 캐릭터 (`fz`)

## 4. 미호크를 만들 때 알게 된 것

- 게임 캐릭터는 동작마다 비트맵 1장(약 200~400장)으로 되어 있어서, **새 캐릭터는 비슷한 기존 캐릭터를 베이스로 다시 칠하고(리스킨) 기술을 재조립**하는 방식이 현실적입니다. 미호크는 이치고 만해(검은 코트+붉은 안감, 검은 검, 초승달 참격)를 베이스로 했고 검 모양은 일본도 그대로입니다.
- 3D 게임 녹화 영상은 배경과 이펙트가 섞여 있어 그림을 그대로 따낼 수 없습니다. 2D 자료가 있으면 꼭 같이 주세요.
- 일러스트의 해상도는 높을수록 좋지만, 게임에 넣을 때는 게임 화질에 맞게 낮춥니다.
